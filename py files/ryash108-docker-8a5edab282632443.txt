# How to Setup the Project

Follow these steps to clone, configure, build, and populate the project data using Docker Compose.

---

## 🛠️ Prerequisites

- **[Git](https://git-scm.com/)**
- **[Docker Engine](https://docs.docker.com/get-docker/)** & **[Docker Compose](https://docs.docker.com/compose/install/)**

---

## 🚀 Setup Steps

### 1. Clone the Repository

```bash
git clone https://github.com/ryash108/docker.git
cd docker
```

### 2. Populate Data Files in `ecommerce/raw-data`

Ensure all required CSV data files are placed inside the `ecommerce/raw-data/` directory:

```text
ecommerce/raw-data/
├── customers.csv
├── discounts.csv
├── employees.csv
├── products.csv
├── stores.csv
└── transactions.csv
```

### 3. Build and Start Services

Start the PostgreSQL database and Django application containers in detached mode:

```bash
docker compose up -d --build postgres django
```

> **Note:** The Django container automatically applies initial database migrations (`makemigrations` and `migrate`) on boot.

### 4. Populate the Database

Populate the database with the raw data files by executing the management command inside the running Django container:

```bash
docker compose exec django python manage.py populate_db
```

### 5. Generate Product Embeddings

Generate vector embeddings for product data:

```bash
docker compose exec django python manage.py generate_embeddings
```

---

## 🌐 Accessing the Application

Once setup is complete, access the application endpoints:
- **Storefront:** [http://localhost:8000](http://localhost:8000)
- **Django Admin Panel:** [http://localhost:8000/admin](http://localhost:8000/admin)

---

## 🔑 Admin Access (Optional)

To create an admin account for the Django Admin Panel:

```bash
docker compose exec django python manage.py createsuperuser
```

---

## 🧹 Stopping Services

Stop containers:

```bash
docker compose down
```

Stop containers and remove database volumes:

```bash
docker compose down -v
```

import os
from fastapi import FastAPI
import psycopg2
from psycopg2.extras import RealDictCursor

app = FastAPI(title="Ecommerce Analytics Service")

def get_db_connection():
    return psycopg2.connect(
        host=os.environ.get("POSTGRES_HOST", "postgres"),
        database=os.environ.get("POSTGRES_DB", "ecommerce"),
        user=os.environ.get("POSTGRES_USER", "postgres"),
        password=os.environ.get("POSTGRES_PASSWORD", "postgrespassword")
    )

@app.get("/health")
def health_check():
    try:
        conn = get_db_connection()
        conn.close()
        db_status = "connected"
    except Exception as e:
        db_status = f"failed: {str(e)}"
    
    return {"status": "ok", "db": db_status}

@app.get("/forecast")
def get_forecast():
    import duckdb
    try:
        con = duckdb.connect('/data/analytics.db', read_only=True)
        # Assuming order_items table exists from ETL
        # Simple aggregation: count of items per product (or random baseline if table is empty)
        result = con.execute("SELECT count(*) as count FROM order_items").fetchall()
        con.close()
        return {"status": "success", "baseline_forecast": {"total_sales": result[0][0]}}
    except Exception as e:
        return {"status": "error", "message": str(e)}

#!/usr/bin/env python
"""Django's command-line utility for administrative tasks."""
import os
import sys


def main():
    """Run administrative tasks."""
    os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'ecommerce.settings')
    try:
        from django.core.management import execute_from_command_line
    except ImportError as exc:
        raise ImportError(
            "Couldn't import Django. Are you sure it's installed and "
            "available on your PYTHONPATH environment variable? Did you "
            "forget to activate a virtual environment?"
        ) from exc
    execute_from_command_line(sys.argv)


if __name__ == '__main__':
    main()

class RegistrationForm(forms.Form):
    # User fields
    email = forms.EmailField(label='Email Address')
    password1 = forms.CharField(widget=forms.PasswordInput(),label='Password')
    password2 = forms.CharField(widget=forms.PasswordInput(),label='Confirm Password')

    # Profile fields
    name = forms.CharField(max_length=250,label='Full Name')
    telephone = forms.CharField(max_length=20, required=False,label='Phone Number')
    city = forms.CharField(max_length=100,label='City')
    country = forms.ChoiceField(choices=Profile._meta.get_field("country").choices,label='Country')
    job_title = forms.CharField(max_length=100,label='Job Title')
    gender = forms.ChoiceField(choices=Profile._meta.get_field("gender").choices,label='Gender')
    date_of_birth = forms.DateField(
        required=False,
        widget=forms.DateInput(attrs={"type": "date"})
    )

    def clean_email(self):
        email = self.cleaned_data["email"]

        if User.objects.filter(email=email).exists():
            raise forms.ValidationError("Email already exists.")

        return email

    def clean(self):
        cleaned_data = super().clean()

        password1 = cleaned_data.get("password1")
        password2 = cleaned_data.get("password2")

        if password1 and password2 and password1 != password2:
            raise forms.ValidationError("Passwords do not match.")

        return cleaned_data

    def save(self):
        # Create the user
        user = User.objects.create_user(
            email=self.cleaned_data["email"],
            password=self.cleaned_data["password1"],
        )

        # Create the profile
        Profile.objects.create(
            user=user,
            name=self.cleaned_data["name"],
            telephone=self.cleaned_data["telephone"],
            city=self.cleaned_data["city"],
            country=self.cleaned_data["country"],
            job_title=self.cleaned_data["job_title"],
            gender=self.cleaned_data["gender"],
            date_of_birth=self.cleaned_data["date_of_birth"],
        )

        return user

from django.contrib.auth.base_user import BaseUserManager
from django.utils.translation import gettext_lazy as _


class CustomUserManager(BaseUserManager):
    """
    Custom user model manager where email is the unique identifiers
    for authentication instead of usernames.
    """
    def create_user(self, email, password, **extra_fields):
        """
        Create and save a user with the given email and password.
        """
        if not email:
            raise ValueError(_("The Email must be set"))
        email = self.normalize_email(email)
        user = self.model(email=email, **extra_fields)
        user.set_password(password)
        user.save()
        return user

    def create_superuser(self, email, password, **extra_fields):
        """
        Create and save a SuperUser with the given email and password.
        """
        extra_fields.setdefault("is_staff", True)
        extra_fields.setdefault("is_superuser", True)
        extra_fields.setdefault("is_active", True)

        if extra_fields.get("is_staff") is not True:
            raise ValueError(_("Superuser must have is_staff=True."))
        if extra_fields.get("is_superuser") is not True:
            raise ValueError(_("Superuser must have is_superuser=True."))
        return self.create_user(email, password, **extra_fields)

from django.contrib.auth import get_user_model
from django.test import TestCase


class UsersManagersTests(TestCase):

    def test_create_user(self):
        User = get_user_model()
        user = User.objects.create_user(email="normal@user.com", password="foo")
        self.assertEqual(user.email, "normal@user.com")
        self.assertTrue(user.is_active)
        self.assertFalse(user.is_staff)
        self.assertFalse(user.is_superuser)
        try:
            # username is None for the AbstractUser option
            # username does not exist for the AbstractBaseUser option
            self.assertIsNone(user.username)
        except AttributeError:
            pass
        with self.assertRaises(TypeError):
            User.objects.create_user()
        with self.assertRaises(TypeError):
            User.objects.create_user(email="")
        with self.assertRaises(ValueError):
            User.objects.create_user(email="", password="foo")

    def test_create_superuser(self):
        User = get_user_model()
        admin_user = User.objects.create_superuser(email="super@user.com", password="foo")
        self.assertEqual(admin_user.email, "super@user.com")
        self.assertTrue(admin_user.is_active)
        self.assertTrue(admin_user.is_staff)
        self.assertTrue(admin_user.is_superuser)
        try:
            # username is None for the AbstractUser option
            # username does not exist for the AbstractBaseUser option
            self.assertIsNone(admin_user.username)
        except AttributeError:
            pass
        with self.assertRaises(ValueError):
            User.objects.create_superuser(
                email="super@user.com", password="foo", is_superuser=False)

from django.contrib.auth.tokens import PasswordResetTokenGenerator
from django.utils import six


# - Password reset token generator method

class UserVerificationTokenGenerator(PasswordResetTokenGenerator):
    def _make_hash_value(self, user, timestamp):
        user_id = six.text_type(user.pk)
        ts = six.text_type(timestamp)
        is_active = six.text_type(user.is_active)
        return f"{user_id}{ts}{is_active}"

user_tokenizer_generate = UserVerificationTokenGenerator()

from django.db import models
from django.conf import settings
from pgvector.django import VectorField

class AnalyticsEvent(models.Model):
    class EventType(models.TextChoices):
        CATEGORY_VIEW = 'category_view', 'Category View'
        SUBCATEGORY_VIEW = 'subcategory_view', 'Subcategory View'
        PRODUCT_VIEW = 'product_view', 'Product View'
        PRODUCT_HOVER = 'product_hover', 'Product Hover (3-20s)'

    user = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        related_query_name='analytics_events'
    )
    session_key = models.CharField(max_length=40, db_index=True)
    event_type = models.CharField(max_length=20, choices=EventType.choices, db_index=True)
    
    # Target entity references (nullable based on event type)
    category_id = models.IntegerField(null=True, blank=True)
    subcategory_id = models.IntegerField(null=True, blank=True)
    product_id = models.IntegerField(null=True, blank=True)
    
    # Metadata
    hover_duration_ms = models.PositiveIntegerField(null=True, blank=True, help_text="Duration in milliseconds")
    timestamp = models.DateTimeField(auto_now_add=True, db_index=True)

    class Meta:
        ordering = ['-timestamp']
        indexes = [
            models.Index(fields=['session_key', '-timestamp']),
            models.Index(fields=['user', '-timestamp']),
        ]

class ProductEmbedding(models.Model):
    product = models.OneToOneField('store.Product', on_delete=models.CASCADE, related_name='embedding')
    vector = VectorField(dimensions=384, null=True, blank=True)

from django.utils import timezone
from datetime import timedelta
from .models import AnalyticsEvent, ProductEmbedding
from store.models import Product
from pgvector.django import L2Distance

def get_recommendations(request, limit=35):
    session_key = request.session.session_key
    user = request.user if request.user.is_authenticated else None
    
    recent_limit = timezone.now() - timedelta(hours=24)
    
    events = AnalyticsEvent.objects.filter(timestamp__gte=recent_limit)
    if user:
        events = events.filter(user=user)
    elif session_key:
        events = events.filter(session_key=session_key)
    else:
        events = AnalyticsEvent.objects.none()
        
    recent_product_views = events.filter(event_type=AnalyticsEvent.EventType.PRODUCT_VIEW).order_by('-timestamp')
    recent_hovers = events.filter(event_type=AnalyticsEvent.EventType.PRODUCT_HOVER).order_by('-timestamp')
    recent_subcategory_views = events.filter(event_type=AnalyticsEvent.EventType.SUBCATEGORY_VIEW).order_by('-timestamp')
    
    recommended_product_ids = set()
    recommendations = []
    
    # 1. High Invasiveness (Direct Product Intent)
    if recent_product_views.exists():
        latest_viewed_id = recent_product_views.first().product_id
        if latest_viewed_id:
            try:
                latest_embedding = ProductEmbedding.objects.get(product_id=latest_viewed_id)
                neighbors = ProductEmbedding.objects.exclude(product_id=latest_viewed_id).order_by(L2Distance('vector', latest_embedding.vector))[:limit]
                for n in neighbors:
                    if len(recommendations) < limit and n.product_id not in recommended_product_ids:
                        recommendations.append(n.product)
                        recommended_product_ids.add(n.product_id)
            except ProductEmbedding.DoesNotExist:
                pass
                
    # 2. Medium Invasiveness (Hover & Subcategory Intent)
    if len(recommendations) < limit and (recent_hovers.exists() or recent_subcategory_views.exists()):
        subcat_id = None
        if recent_hovers.exists():
            subcat_id = recent_hovers.first().subcategory_id
        elif recent_subcategory_views.exists():
            subcat_id = recent_subcategory_views.first().subcategory_id
            
        if subcat_id:
            subcat_products = Product.objects.filter(sub_category_id=subcat_id).exclude(id__in=recommended_product_ids)[:limit - len(recommendations)]
            for p in subcat_products:
                recommendations.append(p)
                recommended_product_ids.add(p.id)
                
    # 3. Low Invasiveness (Broad Browsing / Cold Start)
    if len(recommendations) < limit:
        # Fall back to random products for now as global top-sellers is not easily calculable without aggregating order items
        fallback_products = Product.objects.exclude(id__in=recommended_product_ids).order_by('?')[:limit - len(recommendations)]
        for p in fallback_products:
            recommendations.append(p)
            recommended_product_ids.add(p.id)
            
    return recommendations

import json
from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt
from django.views.decorators.http import require_POST
from .models import AnalyticsEvent

@csrf_exempt
@require_POST
def ingest_events(request):
    try:
        # Ensure session exists if user is anonymous
        if not request.session.session_key:
            request.session.save()
        
        session_key = request.session.session_key
        user = request.user if request.user.is_authenticated else None

        data = json.loads(request.body)
        
        # Handle both single event dict and list of events
        events_data = data if isinstance(data, list) else [data]
        
        events_to_create = []
        for event in events_data:
            event_type = event.get('event_type')
            if not event_type:
                continue
                
            events_to_create.append(AnalyticsEvent(
                user=user,
                session_key=session_key,
                event_type=event_type,
                category_id=event.get('category_id'),
                subcategory_id=event.get('subcategory_id'),
                product_id=event.get('product_id'),
                hover_duration_ms=event.get('hover_duration_ms')
            ))
            
        if events_to_create:
            AnalyticsEvent.objects.bulk_create(events_to_create)

        return JsonResponse({"status": "accepted"}, status=202)
        
    except json.JSONDecodeError:
        return JsonResponse({"error": "Invalid JSON"}, status=400)
    except Exception as e:
        return JsonResponse({"error": str(e)}, status=500)

from decimal import Decimal
from store.models import ProductVariant

class Cart():
    def __init__(self, request):
        self.session = request.session
        # Returning user - obtain his/her existing session
        cart = self.session.get('session_key')
        # New user - generate a new session
        if 'session_key' not in request.session:
            cart = self.session['session_key'] = {}
            
        self.cart = cart

    def add(self, variant, product_qty):
        variant_id = str(variant.id)
        if variant_id in self.cart:
            self.cart[variant_id]['qty'] = product_qty
        else:
            self.cart[variant_id] = {'price': str(variant.product.production_cost), 'qty': product_qty}
            
        self.session.modified = True

    def delete(self, variant_id):
        variant_id = str(variant_id)
        if variant_id in self.cart:
            del self.cart[variant_id]
        self.session.modified = True

    def update(self, variant_id, qty):
        variant_id = str(variant_id)
        if variant_id in self.cart:
            self.cart[variant_id]['qty'] = qty
        self.session.modified = True

    def __len__(self):
        return sum(item['qty'] for item in self.cart.values())

    def __iter__(self):
        all_variant_ids = self.cart.keys()
        variants = ProductVariant.objects.filter(id__in=all_variant_ids).select_related('product', 'color', 'size')
        cart = self.cart.copy()

        for variant in variants:
            cart[str(variant.id)]['variant'] = variant
            cart[str(variant.id)]['product'] = variant.product

        for item in cart.values():
            item['price'] = Decimal(item['price'])
            item['total'] = item['price'] * item['qty']
            yield item    
            
    def get_total(self):
        return sum(Decimal(item['price']) * item['qty'] for item in self.cart.values())

    def clear(self):
        # Remove cart from session
        del self.session['session_key']
        self.session.modified = True

from django.shortcuts import render
from .cart import Cart
from store.models import ProductVariant
from django.shortcuts import get_object_or_404
from django.http import JsonResponse

def cart_summary(request):
    cart = Cart(request)
    return render(request, 'cart/cart-summary.html', {'cart':cart})

def cart_add(request):
    cart = Cart(request)
    if request.POST.get('action') == 'post':
        variant_id = int(request.POST.get('variant_id'))
        product_quantity = int(request.POST.get('product_quantity'))
        
        variant = get_object_or_404(ProductVariant, id=variant_id)
        
        cart.add(variant=variant, product_qty=product_quantity)
        cart_quantity = cart.__len__()
        response = JsonResponse({'qty': cart_quantity})
        return response
        
def cart_delete(request):
    cart = Cart(request)
    if request.POST.get('action') == 'post':
        variant_id = int(request.POST.get('variant_id'))
        cart.delete(variant_id=variant_id)
        cart_quantity = cart.__len__()
        cart_total = cart.get_total()
        response = JsonResponse({'qty':cart_quantity, 'total':cart_total})
        return response

def cart_update(request):
    cart = Cart(request)
    if request.POST.get('action') == 'post':
        variant_id = int(request.POST.get('variant_id'))
        product_quantity = int(request.POST.get('product_quantity'))
        cart.update(variant_id=variant_id, qty=product_quantity)
        cart_quantity = cart.__len__()
        cart_total = cart.get_total()
        response = JsonResponse({'qty':cart_quantity, 'total':cart_total})
        return response

from django.shortcuts import render, redirect

from .models import ShippingAddress, Order, OrderItem
from cart.cart import Cart


def checkout(request):
    context = {}
    if request.user.is_authenticated:
        try:
            shipping_address = ShippingAddress.objects.get(user=request.user)
            context["shipping"] = shipping_address
        except ShippingAddress.DoesNotExist:
            context["shipping"] = {
                "full_name": f"{request.user.first_name} {request.user.last_name}".strip() or request.user.username,
                "email": request.user.email,
            }

    return render(request, "payment/checkout.html", context)


import uuid

def complete_order(request):
    if request.method != "POST":
        return JsonResponse({"success": False}, status=405)

    name = request.POST.get("name")
    email = request.POST.get("email")

    address1 = request.POST.get("address1")
    address2 = request.POST.get("address2")
    city = request.POST.get("city")
    state = request.POST.get("state")
    zipcode = request.POST.get("zipcode")

    shipping_address = (
        f"{name}\n"
        f"{address1}\n"
        f"{address2}\n"
        f"{city}\n"
        f"{state}\n"
        f"{zipcode}"
    )

    cart = Cart(request)
    total_cost = cart.get_total()
    
    invoice_id = str(uuid.uuid4())

    if request.user.is_authenticated:
        order = Order.objects.create(
            invoice_id=invoice_id,
            shipping_address=shipping_address,
            invoice_total=total_cost,
            user=request.user,
        )
    else:
        order = Order.objects.create(
            invoice_id=invoice_id,
            shipping_address=shipping_address,
            invoice_total=total_cost,
        )

    for i, item in enumerate(cart, start=1):
        variant = item.get("variant")
        product = item.get("product")
        qty = item["qty"]
        price = item["price"]
        line_total = price * qty
        
        kwargs = {
            "order": order,
            "line_number": i,
            "product": product,
            "product_variant": variant,
            "quantity": qty,
            "unit_price": price,
            "line_total": line_total,
        }
        
        if variant:
            kwargs["sku"] = variant.sku or ""
            kwargs["size"] = variant.size.name if variant.size else ""
            kwargs["color"] = variant.color.name if variant.color else ""

        if request.user.is_authenticated:
            kwargs["user"] = request.user

        OrderItem.objects.create(**kwargs)

    # Clear the cart
    cart.clear()

    return redirect('payment-success')


def payment_success(request):
    return render(request, "payment/payment-success.html")


def payment_failed(request):
    return render(request, "payment/payment-failed.html")

// Standalone Analytics Module
const Analytics = {
    endpoint: '/api/analytics/events/',
    
    sendEvent: function(data) {
        if (navigator.sendBeacon) {
            navigator.sendBeacon(this.endpoint, JSON.stringify(data));
        } else {
            fetch(this.endpoint, {
                method: 'POST',
                body: JSON.stringify(data),
                keepalive: true,
                headers: {
                    'Content-Type': 'application/json'
                }
            });
        }
    },
    
    init: function() {
        this.trackPageView();
        this.trackHoverEvents();
    },

    trackPageView: function() {
        const body = document.body;
        const categoryId = body.getAttribute('data-category-id');
        const subcategoryId = body.getAttribute('data-subcategory-id');
        const productId = body.getAttribute('data-product-id');
        
        let eventType = null;
        if (productId) eventType = 'product_view';
        else if (subcategoryId) eventType = 'subcategory_view';
        else if (categoryId) eventType = 'category_view';
        
        if (eventType) {
            this.sendEvent({
                event_type: eventType,
                category_id: categoryId,
                subcategory_id: subcategoryId,
                product_id: productId
            });
        }
    },

    trackHoverEvents: function() {
        const productCards = document.querySelectorAll('.product-card');
        
        productCards.forEach(card => {
            let hoverStartTime = 0;
            
            card.addEventListener('mouseenter', () => {
                hoverStartTime = Date.now();
            });
            
            card.addEventListener('mouseleave', () => {
                if (hoverStartTime === 0) return;
                
                const hoverDurationMs = Date.now() - hoverStartTime;
                const productId = card.getAttribute('data-product-id');
                const categoryId = card.getAttribute('data-category-id');
                const subcategoryId = card.getAttribute('data-subcategory-id');
                
                // Fire product_hover ONLY IF duration >= 3000ms AND duration <= 20000ms
                if (hoverDurationMs >= 3000 && hoverDurationMs <= 20000 && productId) {
                    this.sendEvent({
                        event_type: 'product_hover',
                        product_id: productId,
                        category_id: categoryId,
                        subcategory_id: subcategoryId,
                        hover_duration_ms: hoverDurationMs
                    });
                }
                
                hoverStartTime = 0; // reset
            });
        });
    }
};

document.addEventListener('DOMContentLoaded', () => Analytics.init());

from pgvector.django import CosineDistance
from django.db.models import Case, When, Value, FloatField, Count, Q, F
from django.db.models.functions import Cast

def product_info(request, product_slug):
    product = get_object_or_404(Product.objects.select_related('embedding'), slug=product_slug)
    variants = product.variants.select_related('color', 'size').all()
    
    # 1. Fetch current product's embedding and colors
    embedding = product.embedding.vector if hasattr(product, 'embedding') else None
    product_colors = list(variants.values_list('color_id', flat=True).distinct())
    
    recommendations = []
    if embedding is not None:
        # 2. Retrieve top 100 nearest products based on vector similarity.
        # We fetch the IDs first to force PostgreSQL to use the vector index (if one exists) 
        # and avoid evaluating complex annotations on the entire table.
        top_100_ids = list(
            Product.objects.exclude(id=product.id)
            .annotate(distance=CosineDistance('embedding__vector', embedding))
            .order_by('distance')[:100]
            .values_list('id', flat=True)
        )
        
        # 3. Re-rank the top 100 inside PostgreSQL using ORM annotations
        num_colors = len(product_colors)
        
        recommendations = (
            Product.objects.filter(id__in=top_100_ids)
            .annotate(
                # Vector similarity (cosine similarity = 1 - cosine distance)
                embedding_sim=Value(1.0, output_field=FloatField()) - CosineDistance('embedding__vector', embedding),
                
                # Category match bonus
                cat_match=Case(
                    When(category_id=product.category_id, then=Value(1.0)),
                    default=Value(0.0),
                    output_field=FloatField()
                ),
                
                # Subcategory match bonus
                subcat_match=Case(
                    When(sub_category_id=product.sub_category_id, then=Value(1.0)),
                    default=Value(0.0),
                    output_field=FloatField()
                ),
                
                # Color overlap count using conditional aggregation
                color_overlap=Count(
                    'variants__color_id',
                    filter=Q(variants__color_id__in=product_colors),
                    distinct=True
                ),
                # Total colors of the candidate product
                total_candidate_colors=Count('variants__color_id', distinct=True)
            )
            .annotate(
                # True Jaccard similarity for colors = intersection / union
                # Union = len(A) + len(B) - intersection
                color_jaccard=Case(
                    When(
                        total_candidate_colors__gt=0,
                        then=Cast('color_overlap', FloatField()) / (
                            Cast('total_candidate_colors', FloatField()) + 
                            Value(float(num_colors)) - 
                            Cast('color_overlap', FloatField())
                        )
                    ),
                    default=Value(0.0),
                    output_field=FloatField()
                )
            )
            .annotate(
                # Final weighted score
                # Weights: 40% Embedding, 20% Category, 20% Subcategory, 20% Color Jaccard
                final_score=(
                    F('embedding_sim') * Value(0.7) +
                    F('cat_match') * Value(0.1) +
                    F('subcat_match') * Value(0.1) +
                    F('color_jaccard') * Value(0.1)
                )
            )
            .order_by('-final_score')[:4]
            # Avoid N+1 in template by prefetching necessary relations
            .select_related('category', 'sub_category')
            .prefetch_related('variants__color')
        )

    context = {
        'product': product, 
        'variants': variants,
        'recommendations': recommendations
    }
    return render(request, 'store/product-info.html', context)

from sentence_transformers import SentenceTransformer
from pgvector.django import L2Distance

search_model = SentenceTransformer("all-MiniLM-L6-v2")

def all_products(request):
    products = Product.objects.all()

    query = request.GET.get('q')
    if query:
        query_vector = search_model.encode(query).tolist()
        products = products.annotate(
            distance=L2Distance('embedding__vector', query_vector)
        ).order_by('distance')


    # Get filter parameters
    category_id = request.GET.get('category')
    subcategory_id = request.GET.get('subcategory')
    color_id = request.GET.get('color')
    size_id = request.GET.get('size')

    if category_id:
        products = products.filter(category_id=category_id)

    if subcategory_id:
        products = products.filter(sub_category_id=subcategory_id)

    if color_id:
        products = products.filter(variants__color_id=color_id)

    if size_id:
        products = products.filter(variants__size_id=size_id)

    products = products.distinct()

    paginator = Paginator(products, 12)
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)

    current_page = page_obj.number
    total_pages = paginator.num_pages

    start_page = max(current_page - 2, 1)
    end_page = min(start_page + 4, total_pages)

    # Ensure we always show up to 5 pages
    start_page = max(end_page - 4, 1)

    page_range = range(start_page, end_page + 1)

    categories = Category.objects.all()
    subcategories = SubCategory.objects.select_related("category")

    colors = Color.objects.all()
    sizes = Size.objects.all()

    # Build dictionary
    subcategory_dict = {}

    for sub in subcategories:
        subcategory_dict.setdefault(sub.category_id, []).append({
            "id": sub.id,
            "name": sub.name,
        })

    context = {
            "page_obj": page_obj,
            "page_range": page_range,
            "categories": categories,
            "subcategories": subcategories,
            "subcategory_dict": json.dumps(subcategory_dict),
            "colors": colors,
            "sizes": sizes,
            "query": query,
        }

    return render(request, "store/all-products.html", context)

from django.core.management.base import BaseCommand

from store.models import Product
from analytics.models import ProductEmbedding

from sentence_transformers import SentenceTransformer


class Command(BaseCommand):
    help = "Generate embeddings for all products"

    def handle(self, *args, **options):
        self.stdout.write("Loading embedding model...")

        model = SentenceTransformer("all-MiniLM-L6-v2")

        products = list(
            Product.objects.select_related(
                "category",
                "sub_category",
            )
        )

        self.stdout.write(f"Generating embeddings for {len(products)} products...")

        texts = [
            " ".join(filter(None, [
                p.description_en or "",
                p.category.name,
                p.sub_category.name,
            ]))
            for p in products
        ]

        vectors = model.encode(
            texts,
            batch_size=128,
            show_progress_bar=True,
            normalize_embeddings=True,
        )

        ProductEmbedding.objects.all().delete()

        embeddings = [
            ProductEmbedding(
                product=product,
                vector=vector.tolist(),
            )
            for product, vector in zip(products, vectors)
        ]

        ProductEmbedding.objects.bulk_create(
            embeddings,
            batch_size=1000,
        )

        self.stdout.write(
            self.style.SUCCESS(
                f"Successfully created {len(embeddings)} product embeddings."
            )
        )

        const variantId = variantSelect.options[variantSelect.selectedIndex].value;
        const qty = qtySelect.options[qtySelect.selectedIndex].value;
        
        if (!variantId) {
            alert('Please select a variant.');
            return;
        }

        const formData = new URLSearchParams();
        formData.append('variant_id', variantId);
        formData.append('product_quantity', qty);
        formData.append('csrfmiddlewaretoken', '{{ csrf_token }}');
        formData.append('action', 'post');

        fetch('{% url "cart-add" %}', {
            method: 'POST',
            body: formData,
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded'
            }
        })
        .then(response => response.json())
        .then(data => {
            document.getElementById("cart-qty").textContent = data.qty;
            alert("Added to cart!");
        })
        .catch(error => console.error('Error:', error));
    });
</script>

import os
import duckdb

print("Starting ETL process...")

# Postgres connection string
pg_host = os.environ.get('POSTGRES_HOST', 'postgres')
pg_db = os.environ.get('POSTGRES_DB', 'ecommerce')
pg_user = os.environ.get('POSTGRES_USER', 'postgres')
pg_pass = os.environ.get('POSTGRES_PASSWORD', 'postgrespassword')
pg_port = os.environ.get('POSTGRES_PORT', '5432')

pg_dsn = f"dbname={pg_db} user={pg_user} password={pg_pass} host={pg_host} port={pg_port}"

# Connect to DuckDB
con = duckdb.connect('/data/analytics.db')

# Install and load postgres extension
con.execute("INSTALL postgres;")
con.execute("LOAD postgres;")

# Attach postgres database
print("Attaching Postgres database...")
con.execute(f"ATTACH '{pg_dsn}' AS pg (TYPE postgres);")

# Copy a sample of OrderItem into DuckDB
# We need to see the exact table name in Postgres. Django usually names it appname_modelname.
# Assuming payment_orderitem based on typical Django conventions.
print("Loading data into DuckDB...")
con.execute("""
    CREATE OR REPLACE TABLE order_items AS 
    SELECT * FROM pg.payment_orderitem;
""")

print("ETL process completed successfully.")
con.close()
